# CC Buddy 原生工作台设计系统

视觉 token 以 `native/Sources/Design/DesignSystem.swift` 为准；共享控件与材质策略在
`Components.swift`，代理品牌身份在 `AgentBrand.swift`。

## 方向

CC Buddy 是本地 AI 工作台。新的界面以清晰的阅读面、通透的导航层、轻盈的悬浮操作组织信息。
系统蓝表达操作与选择，代理品牌仅用于身份识别。视觉面向最新 macOS 的材质与空间语言；
实现只使用公开 API，当前采用 macOS 26 的 Liquid Glass，不声明或依赖未经验证的 macOS 27 API。

设计遵循 Apple 的直接反馈、可打断弹簧、空间一致性与无障碍原则。玻璃承载操作，正文使用实色：
既让控制层轻盈，也让长对话始终容易阅读。

## 材质与颜色

| 层 | 实现与用途 |
|---|---|
| 侧栏 | 原生 `NSVisualEffectView` 的 sidebar 材质，跟随窗口激活状态，叠加语义色调 |
| 会话流 | `list` 实色，安静的连续浏览面 |
| 阅读画布 | `background`，实体 `surface` 阅读区 |
| 搜索、阅读工具条 | macOS 26+ 公开 `glassEffect(.regular)`，旧系统使用 `regularMaterial` |
| 选中行 | 低饱和蓝 `selection`，文字加重，并在会话流增加位置指示条 |
| 悬浮操作 | 玻璃与明确命中区；阴影只用于临时浮层 |

`CCGlassSurface` 统一响应无障碍设置：减少透明度时切换实色，增加对比度时使用实色与 2pt 描边。
正文使用 `foreground`；次级信息使用 `mutedForeground`，不叠加透明度。
强调文字使用独立 `accentText` 保持小字号对比度。状态颜色配有文字或符号，不靠颜色单独传达状态。

## 几何、文字与反馈

系统字体：Display 34 / Title 24 / Heading 16 / Body 14 / Caption 12 / Label 11。
大标题采用轻微负字距，正文保留系统节奏。用户可在设置中调整对话字号。

间距使用 4pt 网格；面板圆角 20，行 12，按钮 10，快捷键 5，徽标 6。
主导航行高 36、分组行高 30，工具控制高 32。正文最大宽度 860，避免大窗口拉长阅读行。
按钮按下立即反馈，使用 response 0.3 / damping 1 的可打断弹簧。
减少动态效果时取消缩放与位移动画，保留短暂颜色与透明度反馈。

## 导航与专注阅读

侧栏默认 224，会话流默认 336；用户可以直接拖动分隔线，双击恢复默认宽度。
宽度与可见性记忆在本机，窄窗口优先给正文留出空间。侧栏允许收起。

侧栏从上到下是品牌、全局搜索、工作空间目的地、会话资料库、网关状态与快捷操作。
资料库持续呈现全部会话、收藏、导入、回收站、代理和项目。目录配置位于设置。

| 快捷键 | 行为 |
|---|---|
| ⌘K | 全局搜索；再次按下关闭 |
| ↑ / ↓、Return、Esc | 搜索结果选择、打开与关闭；输入法组词期间不拦截 |
| Page Up / Page Down | 在全部搜索结果中按组移动；长结果集保持惰性加载 |
| ⌘F | 聚焦当前会话的消息搜索；Return 跳转下一个匹配 |
| ⌘⇧S | 专注阅读；恢复时还原进入前的三个栏位状态 |
| ⌘1…⌘6 | 会话、时间线、服务、监控、技能、插件 |
| ⌘R / ⌘, | 更新索引 / 设置 |

阅读区右下角提供轻量的专注与最新消息控件。专注模式上方始终有退出入口，
侧栏与会话流恢复按钮分开布局。进入其他目的地会先恢复原布局。
专注期间的可见性不会写入已保存布局，异常退出后重新打开也恢复上一次明确设置的栏位。
菜单命令共享应用语言状态，独立于系统菜单语言与窗口 locale 的作用域。

## 搜索体验与本地加速

搜索面板最大宽 720，距顶 56，高度随窗口自适应。空查询展示最近会话；输入查询后展示匹配片段。
键盘选中项按会话文件身份保留，因此异步语义排序不会把用户正在选中的条目换成另一个。

性能面板在搜索框下展示实际引擎诊断与本地语义排序开关。tgrep 与 Apple Neural Engine 的能力、
降级状态和耗时来自服务层；UI 不估算加速倍数，不将可用硬件等同于已经执行的计算。
搜索关闭后，会话流继续使用当前查询，并提供明确的查询标签与清除按钮。

## 阅读与其他目的地

会话标题、终端继续和分析操作组成首层；项目、分支与统计为第二层；消息搜索与子代理切换
位于同一玻璃工具条。用户消息使用轻柔实色底，助手正文以字阶和间距区分，工具与思考保持可折叠。
概览是与正文并列的可收起面板，统计与消息导航各自成组。

服务页以 48pt 身份图标、主标题与连接状态建立层级；监控、技能、插件、时间线和设置使用同一套
面板、按钮、颜色与空态。新增布局保持原有自动化 ID，避免容器覆盖子元素标识。

## 验收

必须验证浅色、深色、减少动态效果、减少透明度、窄窗口和宽窗口。使用原生 UI 测试覆盖导航、
搜索键盘交互、选择与恢复、导入导出、会话操作、服务与设置流程，并检查颜色对比度与视觉 proof sheets。
执行构建、单元测试与完整 UI 测试后，PR 的 CI 成功才视为交付完成。
