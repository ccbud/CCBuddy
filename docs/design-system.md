# CC Buddy 设计系统

> 代码是唯一真相：`native/Sources/Design/DesignSystem.swift` 定义 token，`Components.swift` 定义控件，
> `AgentBrand.swift` 定义 agent 身份。改视觉先改这三个文件，再改本文。

## 设计命题

CC Buddy 融合三条血统，界面必须读起来像一件东西：

- **Wake** 给结构：不透明的暖中性材质梯度，靠色差分栏而不是描边；常驻界面零投影；三栏选择模型。
- **Claude** 给温度与强调色：暖纸而非冷灰，主操作与选中态用陶土色而不是系统蓝。
- **cc-switch** 给网关词汇：状态用下面的语义三色表达，不自带第二套配色。

浅色是暖纸与暖灰，深色是暖墨。禁止黑底霓虹、终端面板、仪表盘卡片墙。

## 五条硬规则

1. 本文件之外不写颜色字面量，只用 `Theme`。
2. 本文件之外不写字号数字，只用 `Typography` 六档。
3. 常驻界面不投影。投影只属于浮层：菜单、弹窗、命令面板、通知。
4. 已经有色差的面不再描边；同色相邻才画 1px `separator`。
5. Agent 身份只由品牌图标承载，绝不用它给行、图标或面板着色。

## 材质梯度（由暗到亮）

| token | 用途 |
|---|---|
| `sidebar` / `titleBar` | 资料库侧栏与其顶部拖拽区 |
| `list` | 中栏：会话流、设置导航、页面 masthead |
| `background` | 阅读区/内容区外层画布 |
| `surface` | 阅读卡、面板、菜单、弹窗 |
| `fill` / `fillSubtle` | 搜索框、徽标底、分段控件轨道 |

选中态 `selection` 是低饱和陶土洗色；侧栏当前目的地用 `sidebarAccent`。
状态色只有三个：`success`（网关在跑）、`danger`（破坏性与失败）、`warning`（降级提示）。

## 字阶（六档 + 对话附档）

Title 22 / Heading 16 / Body 14 / Caption 12 / Label 11，另有 Display 28 只用于「关于」。
对话正文附档：用户 13.5、助手 13、thinking 11.5、等宽 12。

文字颜色三级：`foreground` / `mutedForeground` / `accentText`。不引入第四种灰，不在 muted 上叠透明度。

间距走 4px 网格（`Space.xs…xxxl` = 4/8/12/16/20/24/32）。
圆角四档：面板 12、行 8、按钮 6、快捷键 5、徽标 4。

## 信息架构

窗口 = 固定 224px 资料库侧栏 + 一个目的地。侧栏不可折叠——可消失的栏会让交通灯悬在任意背景上，
并逼每个目的地维护两套布局。

侧栏自上而下：拖拽区（交通灯）→ 品牌字标 → 全文搜索行（⌘K，点开面板而非内联输入）→
四个目的地（会话/服务/监控/插件）→ 仅在「会话」下展开的资料库分组（全部会话/收藏/已导入/回收站，
代理，项目）→ 页脚（网关状态 + 次级动作 + 齿轮）。

**⌘K 面板**：宽 680、距顶 72，大号无框输入置顶；空态/无结果 250 高，结果列表 460 高；
结果行 = 品牌图标 + 标题 + 项目·时间 + 单行片段；页脚左「搜索范围：全部会话」，右 `↑↓` `↩` `esc`。
它复用同一套全文搜索，因此关掉面板后会话流仍按同一查询过滤，侧栏行会显示这个查询。

**设置是独立场景，不是侧栏目的地**，由页脚齿轮与 ⌘, 进入，固定为 常规 / 会话位置 / 网关 / 数据 / 关于。
历史目录属于「会话位置」，不是导航分组——它是存储配置，侧栏按代理和项目分组才是人真正的浏览方式。

各目的地自带 masthead：标题带承接窗口拖拽区，用 `list` 材质加一条 hairline，不由外壳横跨三栏画色带。

## 侧栏几何

交通灯关闭按钮在 (20, 11)、直径 13.5，中心落在 x = 26.75。侧栏所有行的**行首元素视觉中心**压在这条线上
（不是左缘对齐）：`Rail.edge` 10、`Rail.leadBox` 18、`Rail.leadInset` 7.75。
分组项 `subIndent` 12 表达从属，一旦缩进就不再压轴——这是预期结果。

行高两级：主导航 32 + Body 14，分组项 26 + Caption 12。

## 详情头部

三段，自上而下：品牌图标 + agent 名 + 项目徽标 + 分支（Label 档 muted）；22px 标题 + 操作区；
路径与统计收成 4px 紧组。**「在终端继续」是唯一主按钮**；收藏与置顶是独立图标按钮；
导出、Finder、删除进「更多」菜单。置顶会话固定排在会话流最前。

## 验收

```bash
xcodegen generate --spec native/project.yml --project native
xcodebuild -project native/CCBuddy.xcodeproj -scheme CCBuddy -destination 'platform=macOS,arch=arm64' build
```

视觉验收至少覆盖：会话空态、选中会话、详情阅读、更多菜单、服务页、设置四页，以及系统浅色与深色。
